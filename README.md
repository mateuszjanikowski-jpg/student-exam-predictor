# Student Exam Success Predictor

Machine learning web application built with Streamlit and Docker.

## Features

- Predicts whether a student is likely to pass an exam
- Uses a Random Forest machine learning model
- Interactive Streamlit interface
- Dockerized application
- Dataset generation and model training included

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Docker
- Git & GitHub
- GitHub Actions (CI/CD)
- Render (Cloud Deployment)
- Terraform (Infrastructure as Code)

## Live Demo

Application deployed on Render:

https://student-exam-predictor-v694.onrender.com

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
